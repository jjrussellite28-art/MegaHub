# The Mega Hub

The Mega Hub for your whole PC. Made for a controller. Start Steam games and any app, browse the web with a Kid mode and parent PIN, and change Wi-Fi, Bluetooth, sound and VPN settings, all without a mouse.

**Early beta for Windows 10 and 11.**

## Download
Go to **Releases** (on the right) and download MegaHub-Beta.zip. Extract it and run Run-Light.cmd.
